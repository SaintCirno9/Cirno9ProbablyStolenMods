# 模组快捷键汇总 / Mod Keybind Hub

- ID：`cirno9.keybind_hub`
- 作者：SaintCirno9

## 功能

每次打开选项窗口时整理快捷键：

- 原版“按键设置”分区中由其他模组加入的条目（包括和快捷键配套的开关），按所属模组拆成独立分区，标题为原版“按键绑定 · <模组名>”（英文为 “KEY BINDS · <模组名>”），统一放在选项窗口末尾，按模组加载顺序排列。原版按键留在原分区。
- 运行中模组的模组配置（`ModConfig`）里的按键项，在该模组的分区里镜像一个可改键条目。按键项包括 `KeyCode` 类型，以及以文本保存键名的项（如势力声望扩展的 `journal_key = "F6"`）。文本项需同时满足：默认值是单个合法键名（排除数字与逗号组合），且配置键名或分类含 `key`、`bind`、`shortcut`、`control`、`热键`、`快捷键`、`按键`、`键位` 之一；改键时写回 `KeyCode` 名称文本。同一模组已在选项窗口注册了同 ID 的按键条目（比较时去掉 `<modId>:` 与 `key_` 前缀）时不再镜像，避免同一键位出现两次并互相标成冲突。两处读写同一个配置项，任一处修改都会写回该模组的配置文件。
- 按键冲突提示：窗口内任一按键条目（含原版）与其他条目绑定同一个键时，在条目名称后显示红色“冲突 ×N”，悬停列出同键条目及其所属模组；按窗口内待应用的按键计算，改键后立即刷新。游戏目录存在 `dev.txt`（开发者工具开启，`DevTools.IsEnabled`）时，写死的 F9 调试面板与 F8 控制台也计入冲突。为本模组分区的条目改键时，名称后改为显示原版的“等待按键 / 已被占用 / 保留键”状态（原版只显示在按键设置分区标题旁）。
- 右键清空：在选项窗口任一按键按钮（含原版与模组自有分区）上右键，把待应用按键设为“无”，点“应用”后才写回。正在等待按键时右键交给原版，绑定为 Right Click。

模组自己选项分区里的快捷键保持原位，不搬移。

## 实现

- 前缀补丁挂在 `GameOptionUIManager.OpenUI`，优先级最低：先调用 `GameOptionRegistry.EnsureVanilla()`，确保原版条目和挂在 `EnsureVanilla` 上补注册的模组条目已经就位，再整理分区。
- 条目归属优先按回调（getter / label）所在程序集对应 `LoadedMod.Assembly`；对不上时依次用 `entry.source` 和 `ModHelper.GameOptionId` 的 `<modId>:` 前缀匹配模组 ID。回调来自游戏程序集且无法匹配模组的条目视为原版。
- 搬移的是原条目对象本身，`id`、`source`、getter / setter 不变，所以原模组的改键、保存、`RemoveBySource` 与重复注册都照常工作；被原模组重新加回原版分区的条目，下次打开窗口时会再次搬出。
- 冲突标记由 `GameOptionUIManager.RefreshRules` 的后缀补丁写入：按原版 `BuildEntry` 的格式重写 `label_<条目ID>` 文本并追加标记，悬停内容通过 `TMPIconHover.CustomLinks` 提供。分区标题行不放提示，避免长文本把标题挤成竖排。
- 右键清空在同一后缀补丁里给按键按钮挂 `IPointerClickHandler` 组件（原版 `Button` 只响应左键），右键时只改原版待应用按键表 `pendingKeys`、刷新按钮文字并调用原版 `RefreshRules()`（该私有方法缺失时只记一次警告并停用右键清空）。原版捕获可绑定 Mouse1~Mouse6，因此按下右键时若 `KeyBindHelper.SuppressHotkeys` 为真（捕获中或当帧刚结束捕获），这次点击不清空。
- 本模组分区与镜像条目的 `source` 为 `cirno9.keybind_hub`。禁用时把搬出的条目放回原版按键分区，并删除镜像条目和本模组分区。

## 局限

- 只能汇总注册到选项窗口或模组配置里的按键；键位存在 PlayerPrefs、ES3 或自建文件里的模组需要单独适配，在代码里直接写死 `Input.GetKeyDown(...)` 的按键无法发现。
- 文本键位依赖模组监听配置项变化（`OnChanged`）才能即时生效；只在加载时读取一次的模组，改键后需重启游戏。
- 选项窗口的按键条目只支持单个键。镜像的模组配置项若实际还要配合 Ctrl / Shift 等修饰键（如需要配合 Ctrl+Shift 的组合快捷键），这里只显示主键，冲突提示也只按主键判断。
- 原版改键时会拒绝已被窗口内其他条目占用的键，镜像条目也参与这一检查。
- 清空后的“无”由各模组自己的 setter 处理。不支持关闭的模组会忽略或改回默认键，例如择优遗传会改回 T / Y；势力声望扩展把配置写成 `None`，运行时仍按 F6 生效，下次启动再把配置改回 F6。
