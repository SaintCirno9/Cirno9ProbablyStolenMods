# 投影仪展示区 / Projector Showcase

- **ID**：`cirno9.projector_showcase`
- **作者**：`SaintCirno9`
- **适配游戏版本**：`0.46D`

## 功能说明

- 为原版**幻影投影仪**（`mirage_projector`）增加独立的**展示区**面板，默认尺寸为 **7×5 格**（与初始展示柜大小一致）。
- 可在游戏“选项”菜单的“投影仪展示区 / Projector Showcase”分区调整宽度（3–16 格）与高度（3–12 格）；调小尺寸时若已有物品位于外侧行列，会先保留当前占用范围，待物品移出后自动缩回，不会吞吃或挤压已有物品。
- 与原版投影仪一致：投影仪处于**生效状态**（电池有电，物品提示显示“已生效”）时，不论摆在店内哪里（仓库、柜台、展示柜、垃圾桶、暗格等），展示区内的商品、招牌、持枪证、黑灯、鉴定证书等都视为摆在展示柜中。生效状态由原版在每晚结算时从电池扣电后更新，因此新放入的投影仪或换电池后，需过一晚才会计入：
  - 参与展示柜客源类型吸引、单类总价值等级判定、挑剔买家与伪装顾客抽取；
  - 参与客源预测面板显示、黑灯激活贴图与悬停概率提示、鉴定证书吸引及晋升替换；
  - 参与展示柜违禁品/赃物招引安检与展示柜安全检查，且不会在全店例行搜查或总资产估算中重复计算。
  - 投影仪没有电或已损坏时，内部物品不计入展示柜。
- 存储面板内部槽位排在原版电池槽（0）、改装模组仓（1）、便签槽（2）之后的索引 3，界面按“电池 | 模组 | 展示区 | 便签”排列，保持与旧存档、说明书自动放入及机器升级模组的兼容。
