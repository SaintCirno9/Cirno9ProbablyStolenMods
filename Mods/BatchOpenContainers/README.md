# 框选批量打开容器 / Batch Open Containers

- ID：`cirno9.batch_open_containers`
- 作者：SaintCirno9
- 版本：1.1.0
- Steam 创意工坊：[3839958730](https://steamcommunity.com/sharedfiles/filedetails/?id=3839958730)

## 功能

左键框选多个属于自己的可打开容器或机器（例如酒瓶、背包、储物箱、可打开的机器设备等），右键任一选中目标时正常弹出右键菜单，并将原版“打开”按钮显示为 **打开全部 (N)**，点击即可一次性打开所有选中的可打开目标。

- 支持酒瓶、背包、储物箱以及带有独立打开窗口的机器设备，沿用游戏原生打开条件、所有权与距离校验。
- 默认优先恢复已记住的窗口位置，仅对首次打开或无记忆位置的窗口从屏幕左上角开始平铺排列，避免窗口重叠；也可切换为层叠或原版位置。
- 临时只想打开单个目标时，按住 `Shift` 再右键即可保留单个物品的“打开”菜单。
- 不改动存档数据结构，不使用敏感能力（`Capabilities` 为空）。

## 模组设置

可在游戏 **选项 → 框选批量打开 / Batch Open** 中随时调整：

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 框选后右键直接打开全部容器 | 关闭 | 开启后框选 2 个及以上未打开容器时，右键直接全部打开（`Shift` + 右键仍弹出菜单） |
| 批量打开窗口排列方式 | 平铺（不重叠网格） | 可选“平铺（不重叠网格）”“层叠（错开叠放）”或“原版位置” |
| 保留已记忆的窗口位置 | 开启 | 开启时仅对无记忆位置的新窗口应用排列；关闭时对本次批量打开的新窗口统一排列 |

## 构建

在仓库根目录执行：

```powershell
dotnet build "Mods/BatchOpenContainers/BatchOpenContainers.csproj" -c Release
```

仅构建不部署到游戏目录时追加 `-p:DeployMods=false`。
