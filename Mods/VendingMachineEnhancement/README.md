# 自动售货机增强 / Vending Machine Enhancement

- ID：`cirno9.vending_machine_enhancement`
- 作者：SaintCirno9
- 版本：1.0.1
- Steam 创意工坊：[3843312107](https://steamcommunity.com/sharedfiles/filedetails/?id=3843312107)

## 功能

为游戏中的**自动售货机**与**自动售水机（饮水机）**补齐完整的改装模组仓支持，翻倍售货机容量升级上限，并修复两台设备窗口位置无法记忆的问题。

- **双设备补齐改装模组仓**：自动售货机与自动售水机均新增独立改装模组仓；将**模组仓扩展工具包**拖到设备核心上即可扩展仓位，每台最多扩展 2 次。
- **三维改装模组生效**：
  - **效率**：降低每晚耗电（扩容与吸引力升级带来的额外耗电同样享受减免）。
  - **性能**：对自动售货机按比例提升有效吸引力、提高每晚成交概率，且突破 100 吸引力后每额外增加设定步长（默认 `50`）再 `+1` 件每晚保底售出；对自动售水机增加每晚售水轮次（每 `+100%` 必加 1 轮，余数按概率触发额外 `+1` 轮）。
  - **质量**：在两台设备原本 `+10%` 售价加成基础上按设置系数叠加售价加成（默认 `10%`）；仅影响售价，不增加吸引力或卖出概率。
- **自动售货机扩容翻倍（最大 14×16）**：容量升级上限从原版 10 次提升至 **20 次**；第 11～20 次交替加宽加高，最高可达 `14×16`（224 格）。自动售水机的储水容量保持不变。
- **悬停提示与窗口位置记忆**：悬停售货机内商品可查看当前加成下的预计成交价或不可售卖提示；悬停设备核心可查看有效吸引力与保底件数、每晚售水轮次、总售价加成、货仓尺寸及模组仓扩展进度。两台设备窗口位置支持正常保存。

## 模组设置

在模组管理界面选中本模组打开设置：

| 键 | 分区 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- | --- |
| `quality_coefficient` | 模组效果 / Module Effects | `10` | `0`–`100` | 质量效果系数（%）：折算到售价加成的比例，设为 `0` 时仅保留基础 `+10%` 售价加成 |
| `performance_coefficient` | 模组效果 / Module Effects | `100` | `0`–`300` | 性能效果系数（%）：影响售货机有效吸引力与售水机每晚售水轮次，设为 `0` 时关闭性能加成 |
| `guaranteed_attractiveness_step` | 模组效果 / Module Effects | `50` | `0`–`500` | 吸引力保底步长：有效吸引力超过 100 后每多该数值 `+1` 件保底售出，设为 `0` 时保持原版最多 3 件保底 |
| `enable_capacity_expansion` | 容量扩建 / Capacity Expansion | `true` | `true` / `false` | 启用 20 级容量扩建（最大 `14×16`）；关闭后交由原版或其他扩建模组接管容量 |

## 兼容与说明

- **售卖与保底机制提示**：自动售货机的“保底售出”沿用原版规则，仅对含店铺零售加价后标价 `≤ 50` 的非奢侈品生效（优先食物/饮料）；高于 `50` 的商品（如多数治疗针、工具、模块、奢侈品）不吃保底，全靠每晚随机概率判定，且同名多件进池概率从第 2 件起逐件减半。想卖较贵物品请先升满基础吸引力并装配**性能模组**（或在设置中提高**性能效果系数**）。
- 新增模组仓追加在设备面板结构末尾，不改变原版槽位编号；已有存档读档后自动适配现有设备并重算耗电与加成。
- 与其他自动售货机模组（如 [More Vending Machines](https://steamcommunity.com/sharedfiles/filedetails/?id=3836658488)）良好兼容：窗口位置记忆不拦截点击入口、夜间售卖判定不短路第三方 `Prefix`/`Postfix`、核心提示采用追加方式，且 20 级容量扩建可在设置中随时关闭让位。
- 停用或卸载本模组前，建议先取出新增模组仓内的改装模组，并移走售货机超出原版 `8×12` 范围摆放的商品，以免丢失。
- 不声明敏感能力（`<Capabilities />`）。

## 构建

在仓库根目录执行：

```powershell
dotnet build "Mods/VendingMachineEnhancement/VendingMachineEnhancement.csproj" -c Release
```

仅构建不部署到游戏目录时追加 `-p:DeployMods=false`。
