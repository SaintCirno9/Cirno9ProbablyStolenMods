# 滑条数字输入 / Slider Numeric Input

作者：SaintCirno9。

## 功能

- 在游戏**选项**窗口与**模组配置**窗口中，点击滑条旁显示的数值即可在原地弹出数值输入框并自动全选当前数字，直接键入目标数值即可精准调整，不再需要反复微调拖拽。
- 支持按键与交互细节：
  - `Enter` / 小键盘 `Enter` 或点击输入框外任意区域：解析输入并按滑条范围（`min` / `max`）与整数约束取整/钳位后更新滑条。
  - `Esc`：仅取消当前数字输入并还原原值，不会连带关闭整个选项或模组配置窗口。
  - 直接点击“应用”按钮时会自动先提交正在输入的数值。
  - 点击“重置”或通过拖动滑条更改数值时，同步刷新并退出编辑状态。
- 对原本没有数值显示的小数滑条（例如音量、对话速度或未安装其他数值显示模组时的模组配置滑条），自动补全右对齐的数值显示并支持点击编辑。
- 对带单位或等比例缩放显示的滑条（例如 `100%`），支持按显示数值直接输入（如输入 `120` 或 `120%`）。
- 选项被游戏规则禁用（`interactable == false`）时，不可进入输入模式并同步灰显。

## 构建

```powershell
dotnet build "Mods/SliderNumericInput/SliderNumericInput.csproj" -c Release
```

默认按仓库部署目标安装到 `<LocalMods>/SliderNumericInput/`。仅构建、不部署时追加 `-p:DeployMods=false`。
