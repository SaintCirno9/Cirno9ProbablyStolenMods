# 势力声望面板重制 / Reputation Interface Remake（ReputationInterfaceRemake）

用横向行式界面替代原版“势力档案”。原版每个势力一根竖向柱，宽度固定，多个模组新增势力或往界面里插入内容后会出现重叠、错位和分页错乱；本模组改为每个势力一行，可滚动，行数不受限制。

## 界面

- 每行：势力颜色条、势力名、当前声望档位、精确数值，以及 -200 到 200 的横条（每 20 一格刻度，0 处加粗）。
- 特性图标在横条上方只排一层。同阈值或相距过近的奖励合为 `×N`；点击展开列表，逐项查看实际阈值，单独操作奖励开关。
- 图标状态：原色显示为生效；偏橙色为已达到阈值但未生效（例如势力声望扩展的势力日志任务尚未完成）；变淡（35% 不透明度）为未达到。
- 悬停图标可预览底部详情。没有开关角标的图标可点击固定详情，再点一次解除固定。沿用原版与各模组自己的提示文本。
- 在游戏原生“选项”（主菜单或局内 Esc → 选项）的“势力声望面板重制”分区中，可随时关闭新版界面（点击应用后恢复原版界面），或开启「调试：显示全部声望条（含未解锁）」在正常新版声望面板中预览未解锁/未触发的势力（如卡特尔、新生同盟、灾变日灯塔，仅预览不修改存档）。
- 本地化：`Localization/zh.csv`、`Localization/en.csv`，其他语言回退到英文。界面上的势力名、档位与特性说明来自游戏和各模组自身的本地化。

## 兼容方式

原版 `layout` 不删除，只设为透明且不接收点击；原版与其他模组仍照常往其中生成或插入势力行。新版界面每 0.25 秒从这些行同步数据：

| 来源 | 处理 |
| --- | --- |
| 原版势力、势力声望扩展的新生同盟、酿酒拓展与香烟拓展共用的外环区等 `StoreReputation` 势力 | 直接读取声望与特性列表；势力名取原版行标题（保留其他模组的改名），图标取原版 `PerkElement`（保留扩展特性图标） |
| 災變日 Disaster Day 的灯塔独占面板 | 识别独占行 `Reputation_Lighthouse` 并过滤同帧内尚未销毁的常规势力旧行；因其特性独立管理而非挂入 `PlayerStore.storeReputations`，按特性自身的 `isAlwaysActive` / `isUnlocked` 判定点亮状态 |
| 深空诊所2077 的医疗声望等直接插入的行 | 读取该行的标题、档位、数值与横条长度；标记阈值按原版公式由纵向位置反推，悬停转发给其自带的提示组件 |
| 势力声望扩展的分页按钮 | 新版界面可滚动，打开期间隐藏；关闭新版界面时恢复 |
| 声望拓展：帮派与投资（关系网拓展） | 显示其额外星标与原说明。可开关的奖励带小拨片角标（向右为开，向左为关），直接点击图标切换，不影响奖励的解锁条件。切到「人物」页时隐藏新版列表，切回「势力」时恢复 |
| 帮派与投资的页签、势力声望扩展的顶部入口 | 在窗口原生按钮下方统一排列，左侧「势力／人物」，右侧「势力档案」。高亮当前页签，保留原按钮文案与行为。切回原版时恢复各模组原有控件 |
| 上层区 Upper Levels 的横向滚动容器 `UL_RepViewport` | 打开前优先捕获原版 `layout` 几何快照；检测到被套壳时，在 `UL_RepViewport` 之外按原布局重建视图并整组隐藏与屏蔽该容器 |
| 垃圾场拓展的拾荒客声望行 | 转发悬停事件时跳过已禁用的原版 `PerkElement` 组件以触发其自定义 `DgmPerkHover`；对非 `PlayerStore` 独立声望行保留原控件称号文本，折叠分组中对空 `perkId` 安全回退名称 |

## 构建

```powershell
dotnet build "Mods/ReputationInterfaceRemake/ReputationInterfaceRemake.csproj" -c Release
```
